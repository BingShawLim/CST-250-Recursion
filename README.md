# CST-250 Activity 3 - Recursion (Bing Shaw Lim)

Four C# console applications that solve problems with recursion. Each folder has its own
solution file, so each app can be opened and run on its own in Visual Studio 2022.

| Folder | What it does |
|---|---|
| CountToOneRecursion | Reduces a number to 1 (even: divide by 2, odd: add 1) |
| FactorialRecursion | Solves n! with iteration and with recursion (BigInteger) |
| GreatestCommonDivisorRecursion | Euclid's algorithm for the greatest common divisor |
| FloodFillRecursion | Recursive flood fill on a 20 x 20 board of walls |
